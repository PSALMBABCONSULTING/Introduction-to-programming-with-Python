This repository documents my learning journey through **[CS50's Introduction to Programming with Python](https://cs50.harvard.edu/python/)**, offered by HarvardX.

My goal is to strengthen my Python programming foundation and apply these skills to **healthcare analytics, data science, automation, and artificial intelligence**.

## About the Course

CS50P is a practical introduction to programming using Python. It covers functions, variables, conditionals, loops, exceptions, libraries, testing, file handling, regular expressions, and object-oriented programming.

## Learning Objectives

By completing this course, I aim to:

- Write clear, readable, and reusable Python programs.
- Apply programming logic to solve practical problems.
- Test and debug Python code effectively.
- Work with files, libraries, and regular expressions.
- Understand object-oriented programming fundamentals.
- Build a final project that addresses a meaningful real-world need.
- Prepare for more advanced work in healthcare data science and AI.
